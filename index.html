    Pertanyaan yang Sering Diajukan

    Jawaban singkat seputar cara kerja, privasi, dan batas pemrosesan di FileKit.

    Benar. FileKit memproses gambar dan PDF langsung di browser menggunakan JavaScript (Canvas API, pdf-lib, pdf.js, dan JSZip). File tidak pernah meninggalkan perangkatmu.

    Tidak ada batas harian. Kamu bisa mengompres, menggabungkan, dan mengonversi file sebanyak yang dibutuhkan selama memori perangkatmu mencukupi.

    Saat ini FileKit mendukung gambar JPG, PNG, WebP, serta dokumen PDF untuk kompresi, penggabungan, dan convert PDF antarformat (PDF ke JPG/PNG maupun gambar ke PDF).

    Untuk mengecilkan ukuran PDF secara signifikan di browser tanpa server, tiap halaman dirender ulang menjadi gambar terkompresi lalu disusun kembali ke dalam PDF baru.

    Tidak perlu. Semua fitur langsung terbuka tanpa login dan tanpa watermark pada file hasil.
